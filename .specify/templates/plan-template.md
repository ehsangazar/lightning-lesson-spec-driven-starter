## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

Answer each gate with a concrete reference to this plan. A "no" is either designed out or
recorded in Complexity Tracking below.

- [ ] **I. Node and TypeScript** - Node 20+, TypeScript with `strict` on. Zero new runtime
      dependencies. No `any`, no `as` used to silence an error, no bare `@ts-expect-error`.
      Public functions have explicit parameter and return types.
- [ ] **II. Pure core, one impure edge** - Business logic is pure functions. Exactly one
      file owns sockets, environment, and the clock, and this plan names it. Time-dependent
      code takes `now: number`; nothing below the server layer calls `Date.now()`. One
      exported concern per file.
- [ ] **III. Behaviour-first testing** - Tests drive the public interface only. No sleeps,
      real timers, or network. Tests pass in any order and alone. Every new behaviour in
      this plan has an acceptance test in the same change.
- [ ] **IV. Fail loud** - Invalid arguments throw `RangeError` or `TypeError`. No error is
      caught and discarded.
- [ ] **V. The agent fence** - This plan does not require changes to the test suite, the
      lockfile, TypeScript or test configuration, CI workflows, or the constitution. If it
      does, stop and report the file rather than planning around it.
